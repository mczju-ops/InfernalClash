## 1. 这是什么

**代理人战争**是一款 **1v1 实时卡牌策略对战**小游戏（玩法参考《皇室战争》）。
两名玩家各守一座**信标**与**两座防御塔**，用**卡牌**召唤生物、施放法术去拆对方的建筑；
先拆掉对方信标的一方获胜，或到时间时塔多的一方获胜。

- 一局 **2 人**（同房间，最多 2 人；第 3 个人进不来）
- 一局约 **5 分钟**（准备 1 分钟 ＋ 战斗 3 分钟，可能再进 1 分钟加时）
- 卡池 **63 张**：基础 11 张（人人初始拥有）＋ 普通 / 稀有 / 史诗 / 传说 各 13 张（9 召唤 ＋ 4 法术）
- 不带人机也能开：房间里任一人敲 `/incl bot on` 即可与训练人机对战

> ★ **1.1.0 换了什么**：新增 **12 张卡**（每阶 2 召唤 ＋ 1 法术）＋ **14 条平衡调整**；
> 并且**所有持弓骷髅单位**（精密猎手 / 沙漠小队的焦骸 / 虫群术师的焦骸）不再射箭，
> 改成**穿透射线**（而且能打到飞在头顶的恶魂/快乐恶魂）。
> 逐张卡的数值见游戏内图鉴，或服主的 `plugins/InfernalClash/cards/*.yml`。

## 3. 安装

1. 把 `InfernalClash-1.0.0.jar` 放进 `plugins/`（**只放一个版本**，同名插件放两个 jar 会随机加载其中一个）。
2. 装好 **MCZJUGameCore-1.1.2.jar**，并让它生成 `plugins/MCZJUGameCore/` 数据目录。
3. **启动服务器**（首次启动会自动生成本插件的配置文件与 63 张卡的卡牌文件）。
4. **配竞技场点位**（*必做，否则开不了对局*）：
   ```
   /incl arena create <竞技场名>      # 站在你要当"基准格"的位置敲，按偏移表一次生成 18 个点位
   /incl arena list                   # 看有没有配齐（必需 12 个）
   /incl arena set <竞技场名>         # 也可以用它重设
   /incl arena remove <竞技场名>      # 删掉
   ```
   > 也可以用 GUI：`/incl arena` 打开编辑界面 —— **左键**把点位绑到你站的方块、**右键**传送过去、
   > **Shift+左键**清除该点位。界面里逐格的含义见文档注释，这里只用三个动作。
   >
   > 点位约定：**信标**取"四格交界线"（格线交点）、**防御塔**取"方块正中央"——
   > `create` 会按偏移表自动算，别手工摆。
5. （可选）配大厅与房间：`plugins/MCZJUGameCore/lobbies.json`（主菜单左键传送到大厅）、
   `plugins/MCZJUGameCore/rooms/infernalclash/*.json`（房间的 `waitLocation` / `returnLocation`）。
   这两件事属于 **MGC** 的配置，本插件只读不写。
6. 重载配置：改完配置文件可以敲 `/incl debug reload` 热重载；
   **改卡牌 / 点位后建议完整重启**最稳（热重载失败时控制台会说清是哪一把键）。

## 4. 一局长什么样

```
等待房间（等人，最多 2 人）
   ↓ 人数够了自动开局（或 /mgc start）
准备阶段 60 秒 ── 你被传送到出生点，自动弹出「选卡界面」
   │              排好 8 张 → 点「确认卡组」
   │              双方都确认 ⇒ 立刻开打；到点没确认 ⇒ 判没确认那方负
   ↓
战斗阶段 3 分钟 ── 出牌、拆塔；第 120 秒起经验双倍
   │              时间到：塔多者胜；塔数相同 ⇒ 进加时
   ↓
加时阶段 1 分钟 ── 任意一方的塔或信标被拆 ⇒ 该方立刻出局
   ↓              加时打完塔数仍相同 ⇒ 平局
结算 ── 聊天栏告诉你「本局获得金币 +N」，然后传送回大厅
```

## 5. 玩法规则

### 5.1 场地与目标物

| 目标物 | 数量 | 血量 | 特点 |
|--------|------|------|------|
| **信标** | 每方 1 座 | **320** | 被拆 ⇒ 该方**立刻失败**（战斗阶段与加时都是） |
| **防御塔** | 每方 2 座（半场两侧各一） | **240** | 会攻击射程内的**敌方召唤物**：**每 0.5 秒 2 点伤害**，射程为 **25×25 格方形**；自带嘲讽 |

★ **嘲讽**：带嘲讽的目标物会把敌方召唤物的注意力吸过去（先打它，再打别的）。
★ **塔不打玩家**；玩家也不会掉血（见 5.6）。

### 5.2 时间轴

| 阶段 | 时长 | 说明 |
|------|------|------|
| 准备 | **60 秒**（1200 tick） | 传送到出生点 + 选卡；双方都确认则提前开打 |
| 战斗 | **3 分钟**（3600 tick） | 经验从 5 点开始涨；**第 120 秒**起进入双倍经验 |
| 加时 | **1 分钟**（1200 tick） | 只在一方塔数相同时才会进；任何一方的塔/信标被拆 ⇒ 立刻结束 |

### 5.3 经验与费用（打牌的"钱"）

- 卡牌上的**费用** = 打出它要花的**经验**。
- 开局 **5 点**；**每 2 秒 +1**；双倍期间**每 1 秒 +1**；**上限 10 点**（经验条就是进度条）。
- 经验**连续累加**（不是离散等级），所以「费用 3 的卡」在你 3 点经验时就能打。
- 经验**不足 ⇒ 这张牌打不出**（不会扣费、不会进冷却）。

### 5.4 怎么出牌

- 卡组 **8 张**，放在快捷栏 **2~9** 格。**右键**使用。
- **召唤卡**：
  - 右键**地面** → 召唤到你瞄的那一格；
  - 右键**空气** → 召唤到**你脚下**（x/z = 你所在格，y = 竞技场地面，飞在天上也一样）；
  - ★ **只能放在己方半场**（敌方半场会拒绝）。
- **法术卡**：同样两种落点方式，但**不受半场限制**（可以对任意区域施放）。
- ★ **每张卡有独立冷却**（原版冷却遮罩会变暗 + 数字倒计时）；**红蓝双方冷却互不影响**。
- ★ **同一张卡在卡组里只能放一次**（放两张会共用一条冷却，且分不清）。

### 5.5 胜负

| # | 情况 | 结果 |
|---|------|------|
| W1 | 战斗阶段，某方**信标被拆** | 该方**立刻失败** |
| W2 | 战斗阶段结束，剩余塔数**不等** | **塔多的赢** |
| W3 | 战斗阶段结束，塔数**相等** | 进**加时**（0:0 也进） |
| W4 | 加时中任意一方的**塔或信标**被拆 | **被拆的那方出局** |
| W5 | 加时结束，塔数仍相等 | **平局** |
| W6 | 双方信标**同时**被拆 | **平局** |

★ 结算：**平局在发金币时算双方"胜"**（但排行榜不计胜场）。

### 5.6 玩家自身

- 进局时获得**常驻效果**：速度 II、夜视、抗性提升 V；**你不会受到任何伤害、也不会死亡**。
- ★ **你不能用武器/弓/物品直接打任何战场单位**（塔、信标、召唤物都不行）——
  想影响战场，**只能用卡牌**：法术能打建筑，召唤物能打建筑。
- 每局内可以**创造飞行**（双击空格起飞），方便你从高处看战场。

### 5.7 投降与掉线

- **投降**：右键快捷栏 **1 号格**的「**投降**」物品 → 「确认投降 / 取消」。
- **掉线 / `/mgc leave` / 中途退出 = 投降**（对面立刻获胜，你记一场负）；
  如果本局**没有其他真人**了，这一局会被**中止**（不记战绩）。
- 对局意外卡住（房间停在"游戏已开始"）：等待最后一名玩家 `/mgc leave`，
  或让管理员敲 `/incl debug room reset` 复位房间。

## 6. 局外成长

### 6.1 金币

| 来源 | 数量 |
|------|------|
| 真人局 · 胜 | **+200** |
| 真人局 · 负 | **+100** |
| 人机局 · 胜 | **+100** |
| 人机局 · 负 | **+0** |
| **首次完成对局**（一次性，含人机） | **额外 +1000** |
| 平局 | 按"胜"发（真人 +200 / 人机 +100） |

> 每局结算后**聊天栏会直接告诉你**「本局获得金币 +N」（首通那一局会多一行）。
> 想改这些数字：`economy.yml` 的 `gold:` 段。

### 6.2 卡包与烈焰粉

- `/incl shop` 打开商店：**100 金币 = 1 包（5 张）**，**1000 金币 = 10 包**。
- 抽到**已有的卡** ⇒ 自动转成**烈焰粉**（不会浪费），数量按稀有度不同。
- 抽到**金色版**且你只有普通版 ⇒ 普通版**自动分解**成烈焰粉，图鉴里变成金卡；
  **金卡只能抽到**，不能合成。
- 抽到**新卡**时那一行会标「**新！**」。

### 6.3 图鉴与解锁

- `/incl cards`（图鉴 + 卡组预设）/ `/incl codex`（只读图鉴）。
- 图鉴按**稀有度**排序：基础 → 普通 → 稀有 → 史诗 → 传说。
- 未解锁的卡：图标是**黑色混凝土**，但**名字、费用、冷却、效果都照常显示**（flavor 那一行写「未解锁」）。
- **点未解锁的卡** ⇒ 弹出确认框，花**烈焰粉解锁**：

| 稀有度 | 解锁价（烈焰粉） | 重复卡转尘 |
|--------|------------------|------------|
| 基础 | 不可合成（初始全有） | — |
| 普通 | **40** | 10 |
| 稀有 | **100** | 40 |
| 史诗 | **400** | 100 |
| 传说 | **1600** | 400 |

> 金卡的重复转尘 = 上表的 **4 倍**。这些数字都在 `economy.yml` 的 `exchange:` 段。
> ★ 基础卡（11 张）**初始就全部拥有**，所以新玩家一进来就有牌可打。

### 6.4 卡组预设与排行榜

- 卡组预设 **3 套**，在 `/incl cards` 里保存／切换；对局里也可以点「下一个卡组」按钮换。
- 排行榜（胜场 / 总场次 / 连胜 / 最高连胜）由 MGC 的展示实体呈现，管理员可用 MGC 指令创建。

## 7. 指令

主指令 `/incl`，别名 `/infernalclash`。

### 7.1 玩家可用（权限 `infernalclash.play`，默认所有人）

| 指令 | 作用 |
|------|------|
| `/incl info` | 查看本插件状态（配置、卡池、竞技场点位是否齐） |
| `/incl shop` | 打开**商店**（买卡包 / 看金币） |
| `/incl cards` | 打开**图鉴 + 卡组预设**（可编辑，未解锁卡可在这里解锁） |
| `/incl codex` | 打开**只读图鉴** |
| `/incl arena` | 打开**竞技场编辑界面**（左键绑定 / 右键传送 / Shift+左键清除） |
| `/incl bot on` | 本房间**开启人机**（单人也能开打；开启后等 1 秒，若有人进来就是正常 1v1） |
| `/incl bot off` | 关闭人机 |

> ★ `shop` / `cards` / `codex` / `arena` 界面**只能由玩家执行**（控制台没有背包）。
> 控制台想开界面请用 MGC 的通用通道：`/menu <界面id> <玩家名>`。

### 7.2 管理员（权限 `infernalclash.admin`，默认 OP）

| 指令 | 作用 |
|------|------|
| `/incl debug mgc` | 看 MGC 注册与房间状态（**排障首选**） |
| `/incl debug room reset` | 把本游戏的房间复位成 `READY`（对局卡住时用） |
| `/incl debug reload` | 热重载所有配置（失败会说清哪把键） |
| `/incl debug profile show <uuid>` | 看某个玩家的局外进度（金币 / 尘 / 卡 / 预设） |
| `/incl debug profile grant <uuid> <金币> [尘]` | 加金币 / 尘 |
| `/incl debug profile setowned <uuid> <卡id,卡id,...>` | 直接替换"已拥有"的卡 |
| `/incl debug grant-all [玩家]` | 给全卡（**连金色版一起给**） |
| `/incl debug reset-collection [玩家]` | 重置收藏（**保留 11 张基础卡**，其余清空；金币 / 尘 / 预设不动） |
| `/incl debug set-gold <玩家> <数量>` | 把金币**设置成**该值（不是加） |
| `/incl debug set-powder <玩家> <数量>` | 把烈焰粉**设置成**该值 |
| `/incl debug infinite-xp [玩家] on\|off` | 本场"打牌不扣经验"（只影响发令者当前那一场） |
| `/incl debug purge-legacy [--yes]` | 清理**遗留实体**（上个版本/上次关服留下的目标物与召唤物）。**默认只报告**，加 `--yes` 才真删 |
| `/incl arena create\|set\|list\|remove <竞技场名>` | 点位的创建 / 重设 / 查看 / 删除 |

> ★ `purge-legacy` 的判据：只删**带本插件标记**、**不在进行中的对局里**、且**在本插件点位 64 格方形内**的实体；
> 没带标记的只报告不删。别把它当"清服"用。

## 8. 配置文件

全部在 `plugins/InfernalClash/` 下。**改完可以用 `/incl debug reload` 热重载**（改点位/卡牌后建议重启）。

| 文件 | 管什么 | 常用改法 |
|------|--------|----------|
| `config.yml` | 大厅展示、人数、时间轴、目标物、竞技场选择、人机 | 见 8.1 |
| `economy.yml` | 稀有度权重/颜色、卡包价格与张数、兑换价、对局金币 | 见 8.2 |
| `display.yml` | **所有界面与提示文案** | 见 8.3 |
| `cards/*.yml` | **63 张卡**逐张定义（费用/冷却/效果/外观） | 见 8.4 |
| `card-texts.yml` | 卡牌的**文案覆盖层**（名字/描述/风味），与数值分离 | 见 8.4 |
| `mob-groups.yml` | 召唤物的**实体组**（"一只变多只"这类） | 见 8.5 |
| `arenas.yml` | 竞技场**点位**（由 `/incl arena` 写，手改也行） | 见 8.6 |

### 8.1 `config.yml`

```yaml
meta:                       # 大厅里展示的游戏条目
  name: "<gold>代理人战争"   # 名字（支持 MiniMessage 颜色）
  icon: TOTEM_OF_UNDYING    # 图标材质
  author: "_YamatoMaya_"
  description: [...]        # 一行或多行描述

game:
  min-players: 2            # 至少几人开局
  max-players: 2            # 房间上限（第 3 个人进不来）

mgc:
  register-game: true       # 是否向 MGC 注册本游戏
  purge-legacy-on-start: true   # 启动后自动清理遗留实体（建议保持开）

phases:                     # 全部以 tick 计（20 tick = 1 秒）
  preparing-ticks: 1200     # 准备阶段 60 秒
  battle-ticks: 3600        # 战斗阶段 180 秒
  double-xp-after-ticks: 2400   # 战斗开始 120 秒后进双倍经验
  overtime-ticks: 1200      # 加时 60 秒
  xp-at-battle-start: 5.0   # 开局经验
  xp-ticks-per-level: 40    # 每 40 tick +1 经验（双倍前）
  xp-ticks-per-level-double: 20 # 每 20 tick +1 经验（双倍中）
  max-level: 10.0           # 经验上限

objectives:
  beacon:
    display-block: BEACON   # 信标外观
    health: 320
    taunt: true             # 带嘲讽
    deals-damage: false     # 信标本身不攻击
    beam-colors: [RED, BLUE]
  tower:
    display-block: WAXED_COPPER_BULB
    display-block-state: { lit: true }
    health: 240
    taunt: true
    disable-vanilla-attack: true   # 关掉原版攻击，改用它自己的光束
    beam-damage: 2                 # 每发伤害
    beam-interval-ticks: 10        # 每 0.5 秒一发
    beam-particle: END_ROD
    range-shape: SQUARE_25         # 射程形状（25×25 格方形）
    half-extent-cells: 12          # 半径 12 格 ⇒ 25 格宽

arena:
  default: ""               # 留空 = 每局从已配的竞技场里**随机**挑一座；填名字 = 固定

combat:
  target-refresh-ticks: 10  # 索敌刷新间隔（0.5 秒）

training:                   # 人机（见 8.7）
  bots: [...]
  spell-rules: {...}
  building-placements: {...}
  building-front: {red: ..., blue: ...}
```

### 8.2 `economy.yml`

```yaml
rarities:                   # 每档的显示颜色 / 卡包权重 / 出金概率
  BASIC:     { color: "<white>",  pack-weight: 0,  gold-chance: 0.0 }   # 基础卡不进卡包
  COMMON:    { color: "<green>",  pack-weight: 50, gold-chance: 0.05 }
  RARE:      { color: "<blue>",   pack-weight: 30, gold-chance: 0.05 }
  EPIC:      { color: "<purple>", pack-weight: 15, gold-chance: 0.05 }
  LEGENDARY: { color: "<red>",    pack-weight: 5,  gold-chance: 0.05 }

pack:
  cards-per-pack: 5         # 一包几张
  price: { 1: 100, 10: 1000 }   # 买 1 包 / 10 包的价格（只能有这两档）

exchange:                   # 重复卡转尘（普通/金卡）与解锁价
  COMMON:    { duplicate-powder: 10,  duplicate-gold-powder: 40,   unlock-price: 40 }
  RARE:      { duplicate-powder: 40,  duplicate-gold-powder: 160,  unlock-price: 100 }
  EPIC:      { duplicate-powder: 100, duplicate-gold-powder: 400,  unlock-price: 400 }
  LEGENDARY: { duplicate-powder: 400, duplicate-gold-powder: 1600, unlock-price: 1600 }

gold:                       # 对局奖励
  win-reward: 200
  lose-reward: 100
  bot-win-reward: 100
  bot-lose-reward: 0
  first-game-bonus: 1000
```

### 8.3 `display.yml`（所有文案）

- 所有**界面标题、按钮名、提示语、错误提示、结算文案**都在这里（`messages:` 段，键名带点）。
- 值支持 **MiniMessage**：`<red>` `<gold>` `<green>` `<bold>` 等；也可以换行（列表形式）。
- 占位符用花括号，例如 `{gold}` / `{card}` / `{cost}` / `{price}` / `{seconds}`。
- 值留空 `""` ⇒ **这一句不发**（适合临时关掉某条提示）。
- ★ 出厂值里**没有** `[待填]` 这种占位符；如果你看到界面上写着 `[待填]`，说明那一把键被写坏了、
  控制台里会有对应告警，照着改回去即可。

### 8.4 `cards/*.yml` 与 `card-texts.yml`

- 每张卡一个文件：`cost`（费用）、`cooldown-ticks`（冷却）、`rarity`、`icon`（材质）、
  `summon`（召唤什么、几只、属性、装备、能力）或 `spell`（形状 + 效果列表）、`flavor`（风味描述）。
- **文案覆盖层** `card-texts.yml` 可以单独改某张卡的 `name` / `description` / `flavor`，
  不必动数值文件 —— 数值与文案分开，改文案不会碰到平衡。
- ★ 卡池是**严格校验**的：写错字段名、写了不存在的实体、法术效果键不认识 ⇒
  **插件会拒绝启动并点名「哪个文件、哪把键、为什么」**（宁可起不来，也不带着半套卡跑）。

### 8.5 `mob-groups.yml`

把"一张卡召唤一群"这类配置集中在这里（例如某个召唤物按组生成、随机取其中几种）。
不写它也能跑（只用单只召唤）。

### 8.6 `arenas.yml`（点位）

- 由 `/incl arena` 写盘（写前自动备份 `arenas.yml.bak`）。
- 一个竞技场 **12 个必需点位**：`beacon.red` / `beacon.blue`、`tower.red.left|right`、`tower.blue.left|right`、
  `spawn.red` / `spawn.blue`、`half.red.1|2`、`half.blue.1|2`；另有 `spectate` 与
  `river.1|2`、`bridge.1.a|b`、`bridge.2.a|b`（非必需）。
- 点位缺失 ⇒ **这一局不会生成任何目标物**（控制台会说你缺哪几个），宁可不打，也不会猜位置。
- 坐标约定：**信标**用**格线交点**（整数 x/z，四格交界线），**防御塔**用**方块正中央**，
  **出生点**在 z 上取交界线、x 取方块中心 —— `/incl arena create` 会自动按这个偏移表算。

### 8.7 `training`（人机）

```yaml
training:
  bots:                     # 可配多套，/incl bot on 时**随机抽一套**
    - name: 训练师安道因     # 侧边栏与日志里显示的名字
      deck:                 # 8 张卡；可以写占位符
        - random            # 随机一张合法卡（不会和别的格重复）
        - steal             # 偷玩家同一格的卡（8 个 steal = 复刻玩家卡组）
        - fireball
        # …共 8 项
  spell-rules:              # 每张法术卡一条**全局**规则（不是每套人机一条）
    fireball: NEAREST_ENEMY        # 1) 打离人机信标最近的敌人
    bloodlust: RANDOM_ALLY_CENTER  # 2) 以随机友方召唤物为中心
    gale_push: RANDOM_ALLY_FACING  # 3) 随机友方召唤物处、沿它的朝向
    healing: RANDOM_ALLY_TARGET    # 4) 对随机友方召唤物单体使用
  building-placements:      # 建筑类召唤牌放哪（只对人机生效）
    allay: BACK              # BACK=塔后方4格 / CENTER=塔正前4格 / FRONT=塔前10格
    sentry: CENTER
  building-front:           # "前"是哪一边（按世界朝向）
    red: WEST
    blue: EAST
```

★ 人机**不能带**：速度药水 / 战术冷却 / 回响 / **援军**（它们都依赖"玩家侧"的状态）；法术卡**必须**在上面 `spell-rules` 里有规则，
否则**启动时直接拒绝**并点名是哪一套、第几项。

## 9. 常见问题

**Q：开不了局，`/incl info` 说点位不全？**
A：`/incl arena list` 看缺哪几个，用 `/incl arena create <名>` 或 GUI 补齐（必需 12 个）。

**Q：我的武器打不动塔，是 bug 吗？**
A：不是。**玩家本体不能直接攻击任何战场单位**（塔 / 信标 / 召唤物都一样）。
拆建筑只能靠**法术**和**召唤物**。

**Q：牌打不出去，提示"冷却中"？**
A：每张卡有独立冷却，看快捷栏物品上的**变暗 + 倒计时**。红蓝双方冷却各自独立。

**Q：经验总是不够？**
A：开局 5 点、每 2 秒 +1、双倍后每 1 秒 +1（上限 10）。想快点就多撑到双倍期，或改 `phases`。

**Q：图鉴里那张卡全黑？**
A：黑色混凝土 = **未解锁**（名字和效果仍然会显示）。点它花烈焰粉解锁。

**Q：买卡包说金币不足？**
A：每局结算会给金币（胜 200 / 负 100 / 首通额外 1000），结算时聊天栏会写「本局获得金币 +N」。

**Q：人机没上场？**
A：`/incl bot on` 需要你在**等待房间**里，且**房间只有你一个人**；开启后等 1 秒。
若 1 秒内进来第二个人，就是正常 1v1（人机不上场）。

**Q：对局卡住、房间显示"游戏已开始"却打不了？**
A：`/incl debug mgc` 看状态；让最后一名玩家 `/mgc leave`，或管理员敲 `/incl debug room reset`。

**Q：场上还立着上一局的塔？**
A：从 `/incl debug purge-legacy`（只报告）看有没有遗留；确认后 `/incl debug purge-legacy --yes` 真删。
正常情况下启动后 1 分钟、以及每局开局前都会自动清一次。

## 10. 排障（看控制台的这些关键字）

| 关键字 | 含义 |
|--------|------|
| `配置校验通过` / `配置重新加载失败` | 配置是否合法（失败会指名文件 + 键） |
| `卡池校验通过` | 63 张卡都装上了 |
| `竞技场点位` / `缺` | 点位是否齐 |
| `对局开始｜真人 N 名` | 一局真的开了 |
| `目标物已就位` / `已生成 … 信标` | 目标物生成 |
| `准备阶段开始：已传送` | 玩家是否被送进场地 |
| `已拦截玩家对目标物的伤害` | 玩家用武器打建筑被拦（正常） |
| `放行卡牌法术对目标物的伤害` | 法术打建筑（正常） |
| `对局结算：… 金币 +N` | 金币是否真的发了 |
| `遗留清理完成：已删除 N 个` | 遗留实体清理（`归属不符` 那一项长期 >0 就要报给作者） |
